# oyaa-viz

Glitch audio-spectrum visualizer on the left, Liquid Lyrics on the right. AMOLED black, red or white.

- Button in the top bar (next to the Marketplace cart) opens/closes the page
- Word-by-word synced lyrics, animated background (tinted red/white), cinema mode, fullscreen, romanization, create/edit sync, full Liquid Lyrics settings (gear icon or profile menu)
- Per-song lyric delay (− / + under the visualizer), red / white switch

Lyrics engine: [Liquid Lyrics](https://github.com/NMWplays/Liquid-Lyrics) by NMW.

## Install
Spicetify Marketplace -> Extensions tab -> oyaa-viz -> Install.
Manual: copy `oyaa-viz.js` to the Spicetify Extensions folder, then
`spicetify config extensions oyaa-viz.js` and `spicetify apply`.
Remove the old custom app and the standalone Liquid Lyrics extension first.
