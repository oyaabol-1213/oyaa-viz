# oyaa-viz

Glitch audio-spectrum visualizer on the left, synced lyrics on the right. AMOLED black, red or white.

- Button in the top bar (next to the Marketplace cart) opens/closes the page
- Word-by-word synced lyrics, animated background (tinted red/white), cinema mode, fullscreen, romanization, create/edit sync, full settings (gear icon or profile menu)
- Per-song lyric delay (− / + under the visualizer), red / white switch

## Install
Spicetify Marketplace -> Extensions tab -> oyaa-viz -> Install.
Manual: copy `oyaa-viz.js` to the Spicetify Extensions folder, then
`spicetify config extensions oyaa-viz.js` and `spicetify apply`.
Remove the old oyaa-viz custom app and any other lyrics extension first.
